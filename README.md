# Homebrew tap for Teleport

[Teleport](https://github.com/ejb1123/teleport) is a remote desktop for Linux hosts.

```sh
brew install --cask ejb1123/teleport/teleport-desktop   # macOS
brew install ejb1123/teleport/teleport-desktop          # Linux
brew upgrade                                            # update
```

The release workflow of ejb1123/teleport updates this tap; do not edit by hand.
